🔌 ENDPOINTS API
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

POST   /api/auth/login              Login do atendente
POST   /api/auth/register           Registrar novo atendente
GET    /api/cardapio                Listar cardápio
POST   /api/pedidos                 Criar pedido (cliente)
GET    /api/pedidos                 Listar pedidos (atendente)
GET    /api/pedidos/:id             Obter detalhes do pedido
PATCH  /api/pedidos/:id/status      Atualizar status (atendente)

   users              - Atendentes (id, username, password_hash)
   cardapio           - Itens do menu (id, nome, preco, categoria)
   pedidos            - Pedidos de clientes (id, mesa, cliente_*, status, total)
   itens_pedido       - Itens de cada pedido (id, pedido_id, cardapio_id, qtd)
